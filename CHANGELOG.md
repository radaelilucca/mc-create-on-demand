# Changelog

## [0.1.0] - 2026-10-25

### Added

- Package completed orders for the address saved from the Stock Keeper, sending exactly the requested quantity and keeping surplus in storage.
- Track the saved destination and packaging progress in the orders panel.

## [0.0.1] - 2026-10-21

### Added

- Request new production from the Stock Keeper, including products with zero stock.
- Craft connected component recipes while reusing ingredients already in storage.
- Preview crafting steps in dependency order or missing materials, with item icons and scrollable lists.
- Track and cancel production orders, and highlight returned products on the next Stock Keeper opening.
- Accept orders by default on new Factory Gauges while preserving the original stock slider.
- Support NeoForge 1.21.1 with Create 6.0.10 and Forge 1.20.1 with Create 6.0.8.
