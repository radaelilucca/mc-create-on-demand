# Development

Use Java 17 for Forge 1.20.1 and Java 21 for NeoForge 1.21.1.

Run `./gradlew buildAll` to build both loaders and run the shared planning tests. Opt into server GameTests with `-PdemandGameTests`.

Keep generated build output, caches and development worlds outside version control. Technical documentation is maintained in Portuguese under [docs](docs/README.md).
